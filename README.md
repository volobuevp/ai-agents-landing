# Landing «Внедрение ИИ-агентов в бизнес-процессы»

Одностраничный лендинг услуг по внедрению ИИ-агентов в компании РФ — живой
сайт **[мир-ии-для-бизнеса.рф](https://xn------8cdeqjpdbae0bh0a1b3a9v.xn--p1ai)**
(хостинг Beget, PHP 8.5). Цель страницы одна — конверсия посетителя в заявку
на бесплатный экспресс-аудит рутины; всё остальное (дизайн, копирайтинг,
форма) работает на этот CTA.

## Какую задачу решает

Продажа внедрения ИИ-агентов — «доверительная» услуга: клиент покупает не
технологию, а уверенность, что его процесс не сломается. Лендинг решает три
подзадачи:

1. **Зацепить** — узнаваемый terminal-дизайн (моноширинная типографика,
   тёмный фон с координатной сеткой, циановые акценты, typewriter-эффект)
   сразу отделяет страницу от типовых шаблонных лендингов.
2. **Обосновать** — офферы сформулированы через результат и деньги
   («аудит → расчёт эффекта → внедрение»), а не через «делаю ботов»;
   ценность подкрепляется 10+ годами отраслевой экспертизы.
3. **Собрать заявку без потерь** — форма с вложениями (ТЗ, скриншоты
   процессов, сметы) доставляет уведомление в мессенджер MAX за секунды,
   с резервным каналом на почту.

## Для кого

Посетитель — **владелец или руководитель небольшой компании РФ**, у которого
рутинные процессы съедают время команды: обработка входящих заявок,
документооборот, сверки, отчётность, ручной перенос данных между системами.
Человек без ИТ-подготовки, поэтому текст без жаргона, а выгода измеряется
в часах и рублях.

## Стек и структура

Без фреймворков и сборщиков — только то, что отдаёт статикой nginx:

```
├── index.html              # 6 семантических секций: hero → польза → почему я → миссия → цены → форма → контакты
├── css/styles.css          # Grid/Flexbox, CSS-переменные, scroll-анимации, mobile-first адаптив
├── js/main.js              # typewriter, IntersectionObserver, маска телефона, honeypot-антиспам, валидация, отправка
├── send.php                # серверная обработка заявки: уведомление в MAX + вложения, копия в Formspree
├── max-config.php          # токены (в git НЕ входит — подключается require'ом)
├── uploads/                # вложения заявок: dl.php (отдача файлов), .htaccess (закрытие папки)
├── privacy.html            # согласие на обработку персональных данных (152-ФЗ)
├── fonts/                  # локальные моноширинные шрифты
└── TECHNICAL_SPEC.md       # дизайн-система: типографика, палитра, анимации, анти-паттерны
```

## Инженерные детали, которыми горжусь

- **Токен MAX-бота не утекает в браузер** — уведомление отправляет серверный
  `send.php`; в публичном JS только адрес обработчика. Formspree — лишь
  резервный канал (бесплатный тариф файлы не принимает, поэтому вложения
  идут через PHP).
- **Защита от path traversal** — вложения хранятся под hex-именами
  (`<32 hex>/<16 hex>.<расширение из белого списка>`), отдаёт `dl.php` со
  строгой регуляркой; оригинальные клиентские имена не хранятся.
- **Ссылки на вложения строятся от константы домена**, а не от заголовка
  `Host` — подменой заголовка нельзя подсунуть в уведомление чужой домен.
- **Антиспам без капчи** — honeypot-поле + проверка на стороне клиента и
  сервера.
- **Папка uploads закрыта** (.htaccess + отдача только через dl.php с
  `Content-Disposition: attachment`) — прямые ссылки не открывают чужие
  файлы в браузере.

## Развёртывание (кратко)

1. Скопировать файлы на хостинг с PHP ≥ 8.0 (деплой — по FTP).
2. Создать `max-config.php` по образцу из `send.php` (токен бота из
   [business.max.ru](https://business.max.ru), `chat_id` получателя,
   публичный адрес сайта в punycode).
3. В `js/main.js` указать свой endpoint Formspree (резервный канал).
